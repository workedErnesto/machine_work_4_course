# Рекомендательная система фильмов

Учебная работа по машинному обучению. Система рекомендует фильмы по данным онлайн-кинотеатра Kion: показывает топ-10 популярных, похожие фильмы по оценкам пользователей и по описанию, похожих пользователей и персональную подборку. Есть ноутбук с анализом данных и проверкой методов, API на FastAPI и интерфейс на Streamlit, в котором можно оценить фильм. Каталог и оценки хранятся в базе SQLite.

## Запуск

1. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Запустить API из папки `app`:

   ```bash
   cd app
   uvicorn main:app
   ```

3. Во втором терминале запустить интерфейс:

   ```bash
   cd app
   streamlit run app.py
   ```

На стартовом экране выберите ID пользователя и нажмите «Продолжить». Разделы и кнопка «Сменить пользователя» находятся в левом меню.

В разделе «Похожие фильмы» нажмите на строку таблицы, чтобы прочитать описание фильма. В разделе «Похожие пользователи» кнопки сравнения открывают оценки обоих профилей по общим фильмам.

Исходный датасет лежит в `data/kion_items.csv` (каталог) и `data/kion_interactions.csv.gz` (просмотры). Вместе файлы занимают около 96 МБ. Ноутбук `movie_recommender_analysis.ipynb` делает из них `data/movies.csv` и `data/ratings.csv`. При первом запуске API переносит эти файлы в базу `data/recommender.sqlite3`, новые оценки из приложения сохраняются туда же.

## Как делали

1. EDA: размер данных, пропуски, распределение доли просмотра, жанры, годы выхода, длина описаний, просмотры по неделям.
2. Предобработка: оставили только фильмы с годом выхода, убрали копии в 4К и просмотры короче 5 минут, взяли фильмы с 300 и больше просмотрами и случайные 4 000 пользователей с 20 и больше просмотрами. Явных оценок в Kion нет, поэтому оценку от 1 до 10 получили из доли просмотра (доля, делённая на 10 и округлённая вверх). Описания привели к начальной форме слов через pymorphy3.
3. Популярные фильмы: взвешенная оценка (vR + mC) / (v + m), где m это 75-й процентиль числа оценок.
4. Коллаборативная фильтрация по фильмам: косинусное сходство после вычитания средних оценок фильмов. Берём пары, у которых не меньше 10 общих зрителей.
5. Коллаборативная фильтрация по пользователям: косинус оценок по общим фильмам после вычитания средней оценки пользователя, умноженный на n / (n + 10).
6. Фильтрация на контенте: TF-IDF по описанию и по жанрам, косинусное сходство, описание 70%, жанры 30%.
7. Персональные рекомендации: прогноз оценки непросмотренных фильмов по 3-30 соседям. Сглаживаем прогноз средним из двух оценок: средней фильма и средней пользователя. Чем меньше соседей, тем больше вес этого среднего.
8. Проверка: спрятали 20% оценок и сравнили прогнозы с простым вариантом «средняя оценка фильма».

## API

Все команды с параметрами описаны на странице `http://127.0.0.1:8000/docs` и в разделе «Справка».

| Пункт задания | Команда |
|---|---|
| Топ-10 популярных фильмов | `GET /api/popular?limit=10` |
| Коллаборативная фильтрация по фильмам | `GET /api/movies/{movie_id}/similar-by-ratings` |
| Коллаборативная фильтрация по пользователям | `GET /api/users/{user_id}/neighbors` |
| 10 рекомендованных фильмов по контенту | `GET /api/movies/{movie_id}/similar` |
| Персональные рекомендации | `GET /api/users/{user_id}/recommendations?method=users` или `method=items` |
| Оценить фильм | `POST /api/ratings` с телом `{"user_id": 4001, "movie_id": 9728, "rating": 8}` |
| Служебные | `GET /health`, `GET /api/status`, `GET /api/search?q=...`, `GET /api/users/{user_id}/ratings` |

ID от 1 до 4000 открывают профили с историей Kion. Оценку от 1 до 10 можно поставить в любом профиле. SQLite хранит свои оценки отдельно от исходных баллов Kion. При расчёте берётся последняя сохранённая оценка, в том числе после повторной оценки фильма.

## Результаты

После отбора осталось 1 734 фильма, 4 000 пользователей и 136 161 условная оценка. Средняя равна 7.35. У 55.6% просмотров балл 10, потому что просмотрели больше 90% фильма.

Точность прогноза спрятанных 20% оценок (ошибка в баллах от 1 до 10):

| Метод | MAE | RMSE | Покрытие, % |
|---|---|---|---|
| Средняя оценка фильма | 2.90 | 3.32 | 100.00 |
| По пользователям без сглаживания | 2.55 | 3.15 | 99.20 |
| По пользователям со сглаживанием | 2.57 | 3.12 | 99.20 |
| По фильмам без сглаживания | 2.68 | 3.29 | 57.71 |
| По фильмам со сглаживанием | 2.70 | 3.22 | 57.71 |

Сглаживание уменьшило RMSE, при этом MAE у обоих методов выросла на 0.02 балла. В приложении по умолчанию стоит сглаженный прогноз по похожим пользователям. У него RMSE 3.12 и покрытие 99.20%.

Из 200 случайных профилей Kion рекомендации получили 199. В их топах до сглаживания было 58.39% десяток по пользователям и 78.29% по фильмам. После сглаживания в проверенных топах десяток не было. Ошибки предсказания считаем отдельно на спрятанных оценках.

Среди 10 фильмов, похожих только по описанию, общий жанр с исходным фильмом есть у 65.7%, у случайной пары фильмов у 48.4%.

Топ-3 популярных: «Прабабушка легкого поведения» (8.76), «Белый снег» (8.69), «Девятаев» (8.55).

## Данные

Датасет MTS Kion (просмотры онлайн-кинотеатра Kion с марта по август 2021 года), открытая версия из соревнования МТС по рекомендательным системам. Описание датасета: статья [MTS Kion Implicit Contextualised Sequential Dataset for Movie Recommendation](https://arxiv.org/abs/2209.00325).
