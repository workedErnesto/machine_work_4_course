# Классификация изображений в Teachable Machine

В первой части модель отличает хот-доги от остальных фотографий. Во второй распознаёт штекеры USB-A, USB-C и HDMI. В ноутбуке также есть гайд по Pocket AutoML и описание приложения, которое распознаёт разъёмы по фотографии.

## Запуск

Нужен Python 3.12. Команды выполняются из папки работы.

1. Создать окружение и установить зависимости.

   ```bash
   python3.12 -m venv ~/.venvs/teachable_machine_images
   source ~/.venvs/teachable_machine_images/bin/activate
   python -m pip install -r requirements.txt
   ```

2. Выполнить ноутбук.

   ```bash
   python -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 notebooks/image_classification.ipynb
   ```

3. Для задания 4 запустить API в первом терминале.

   ```bash
   source ~/.venvs/teachable_machine_images/bin/activate
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8010
   ```

4. Во втором терминале запустить интерфейс.

   ```bash
   source ~/.venvs/teachable_machine_images/bin/activate
   python -m streamlit run app/app.py --server.address 127.0.0.1 --server.port 8510 --server.headless true
   ```

5. Открыть [приложение](http://127.0.0.1:8510), загрузить JPG или PNG и нажать «Распознать». Для проверки подойдёт `data/connectors/test/usb_a/usb_a_01.jpg`. [Документация API](http://127.0.0.1:8010/docs).

## Структура

| Путь | Что там |
|---|---|
| `notebooks/image_classification.ipynb` | Задания 1, 2 и 4, гайд по заданию 3 |
| `data/hot_dogs/` | Фотографии из примера преподавателя и результаты проверки в сервисе |
| `data/connectors/` | Фотографии разъёмов, скриншоты и таблица источников |
| `models/` | Два экспорта Keras и подписи к классам |
| `app/main.py` | API на FastAPI, принимает фото и возвращает класс и уверенность |
| `app/app.py` | Форма загрузки на Streamlit |

## Как делали

1. Для хот-догов использовали папки из примера преподавателя. Модель проверили на 21 фото в Teachable Machine и на всех 500 фотографиях из проверочных папок в Jupyter. При подсчёте точности на новых снимках убрали один повтор из обучающей папки.
2. Для разъёмов собрали по 25 фотографий на класс. По 20 загрузили в Teachable Machine, оставшиеся 5 проверили после обучения. В `data/connectors/sources.csv` записали авторов, ссылки на оригиналы и лицензии. Кадрированные фотографии распространяются на условиях указанных лицензий.
3. Обе модели экспортировали в Keras. В Jupyter обработали снимки по коду экспорта и посчитали точность по каждому классу.
4. Для задания 3 в ноутбуке указали, какие снимки взять для первого обучения, проверки с исправлениями и повторной проверки в Pocket AutoML. Скриншоты и результаты добавляются после прогона на Android.
5. Для задания 4 подключили модель разъёмов из задания 2 к API. Форма отправляет фотографию в `POST /predict` и показывает класс и уверенность модели для выбранного снимка.
